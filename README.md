# WorkSure — Controller Request Object Milestone

This `controller-request-submission` branch contains the controller/request-object update requested for the current university Advanced OOP project milestone.

## Milestone scope

- All controllers were reviewed.
- JSON `@RequestBody` inputs were converted from generic `Map` bodies to typed request DTO classes where applicable.
- Controller request-object and request compatibility regression tests are included.

| Content | Directory |
